PROJET 03 Outil d’équipe · Démo navigateur

CollabBoard

Un tableau Start / Stop / Continue pour rassembler les idées et préparer un compte rendu de rétrospective.

  • JavaScript
  • HTML
  • CSS
  • Stockage local
Essayer la démo ↗ Lire le guide ↗
← Retour à tous les projets

Le besoin

À la fin d’un cycle de travail, une équipe peut noter ce qu’elle veut commencer, arrêter ou continuer. Le tableau organise ces retours en trois colonnes simples.

Fonctionnalités

  • Ajouter et supprimer des idées.
  • Déplacer les cartes par glisser-déposer ou avec le sélecteur.
  • Distribuer au maximum cinq votes sur l’ensemble du tableau.
  • Retrouver ses changements dans le navigateur et réinitialiser les exemples.
  • Télécharger un compte rendu au format Markdown.

Ce que je travaille

Les cartes sont créées avec JavaScript et ajoutées au document. Les textes utilisateurs sont insérés comme texte, puis les données sont sauvegardées au format JSON dans le stockage local du navigateur.

Organisation

  • public/index.html : structure du tableau.
  • public/board.css : styles et affichage responsive.
  • public/board.js : cartes, votes, stockage et export.
  • api/ : endpoint PHP distinct pour une future synchronisation.

À savoir

Les changements sont conservés uniquement dans le navigateur utilisé : les équipes ne partagent pas encore leurs tableaux. L’export PDF et la synchronisation avec l’API ne sont pas implémentés dans la démo.

Prochaine étape

Ajouter une authentification et connecter un tableau à la base de données pour le partager avec une équipe.
