## Ouvrir en local

1. Clonez le dépôt ou téléchargez-le.
2. Pour consulter le portfolio, ouvrez `index.html` dans un navigateur.
3. Les démos StockPulse et CollabBoard sont autonomes et conservent les données de démonstration dans le navigateur utilisé.
4. Pour exécuter les parties PHP, installez PHP 8 avec PDO MySQL et MySQL/MariaDB, puis suivez le guide de chaque projet et importez son schéma SQL.

Les identifiants MySQL indiqués dans les guides ne sont que des valeurs par défaut de développement local. Configurez un compte dédié et des secrets dans l’environnement pour toute autre utilisation.
